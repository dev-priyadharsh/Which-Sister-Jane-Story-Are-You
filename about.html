About this project

The thinking behind the quiz

This is a concept piece — a customer-facing quiz exploring what an AI-assisted feature could look like for a fashion brand like Sister Jane, built to sit at the intersection of playful brand storytelling and applied AI.

Every result starts from simple, reliable logic: six answers, tallied against four style archetypes. Layered on top, a short line of the result is rewritten live by Gemini, referencing the shopper's actual choices, so two people rarely read quite the same words. If that call doesn't come back for any reason, the quiz still gives a complete, considered result — the AI is an enhancement, never a dependency.

  • FrontendHTML, CSS, vanilla JS — no framework
  • BackendOne Vercel serverless function
  • AIGoogle Gemini API
  • HostingVercel
